# BioБағдар (GitHub Pages + Firebase Spark, без облачных функций)
Сайт на GitHub Pages, данные в Firebase (Authentication + Firestore), бесплатный тариф Spark.

Без серверной логики: баллы считает браузер учителя при проверке (ключи читает только учитель, ученик их не видит), подтверждение ключей перед контрольной проверяет интерфейс учителя. Сроки, число попыток и принадлежность к группе проверяют правила Firestore.
Не перенесено из демо: теория, схемы, помощник «Био», коллекция, дневник ошибок, банк импортированных заданий, таймер контрольной.
